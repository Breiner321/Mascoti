# RF-09: Directorio Georreferenciado de Clínicas

> **Semana:** 3 · **Ubicación en el código:** `plugins/directorio`
>
> Lee también la sección **Adaptación a Firebase** al final: prevalece sobre el texto original cuando hay conflicto.

## Módulo

Módulo: Dueño de Mascota

## Actor(es)

Usuario Dueño de Mascota; API de Google Maps; Backend/API

## Precondiciones

1. El usuario otorgó permisos de geolocalización a la app.

## Disparador (Trigger)

El dueño accede a la pestaña "Clínicas Cercanas" del menú principal.

## Flujo Principal (Paso a Paso)

1. [Frontend] Solicita permisos de ubicación al sistema operativo (si no fueron otorgados previamente).
2. [Usuario] Acepta el permiso de ubicación en el diálogo nativo del sistema operativo.
3. [Frontend] Obtiene las coordenadas (lat, lng) actuales del dispositivo mediante el GPS.
4. [Frontend] Envía GET /clinics/nearby?lat={lat}&lng={lng}&radius=10km al backend.
5. [Backend/API] Ejecuta una consulta geoespacial (geohash o extensión PostGIS) sobre la colección clinics filtrando por estado:'activo' y radio de 10 km.
6. [UI] Renderiza un mapa (Google Maps SDK) centrado en la ubicación del usuario, con marcadores personalizados por cada clínica encontrada.
7. [Usuario] Pulsa sobre un marcador para ver una tarjeta con nombre, calificación, distancia, horario y botón "Ver Perfil".
8. [Usuario] Opcionalmente aplica filtros: tipo de animal atendido, servicios disponibles, o distancia máxima.
9. [Frontend] Reejecuta la consulta con los parámetros de filtro y actualiza los marcadores del mapa dinámicamente.

## Flujos Alternativos y Excepciones

- Permiso de ubicación denegado: El sistema muestra un mensaje explicativo y ofrece la alternativa de buscar por dirección/ciudad manualmente en un campo de texto con autocompletado de Google Places.
- Sin clínicas en el radio: Se muestra el mensaje "No encontramos clínicas cerca. Intenta ampliar el radio de búsqueda" con un control deslizante para aumentar el radio.
- GPS no disponible/impreciso: Si la precisión del GPS es baja (>500m de margen de error), se muestra un aviso no bloqueante indicando posible imprecisión en los resultados.

## Postcondiciones

- El dueño visualiza en el mapa las clínicas cercanas relevantes y puede continuar hacia el agendamiento (RF-13).

## ⚠️ Adaptación a Firebase (prevalece sobre el texto original)

- No hay PostGIS: consulta geoespacial con **geohash** (`geoflutterfire_plus`) sobre `clinics` (`estado == 'activo'`). No se necesita endpoint `/clinics/nearby`.
- Requiere API key de Google Maps SDK para Android (restringida por SHA-1 del APK).
- **Cambio de alcance 4:** el mapa muestra también las veterinarias de OpenStreetMap que aún no usan Mascoti (Edge Function `veterinarias-cercanas`, sin Google Maps ni Places), con marcador distinto, leyenda, distintivo "Aliado Mascoti", chip "Solo aliados" y recarga automática al mover el mapa. Las no aliadas solo tienen "Cómo llegar" y "Llamar" (sin "Agendar"). Ver [cambios-alcance.md](../cambios-alcance.md#cambio-4--mapa-con-todas-las-veterinarias-y-aliados-mascoti).
